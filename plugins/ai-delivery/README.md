# ai-delivery plugin

Thin host plugin for `@aviaratech/ai-delivery`. The launcher starts the installed package's `mcp:serve` command over stdio. MCP schemas, GitHub operations, worktree handling, and delivery logic remain in the package.

The bundled skills cover issue intake, prepared worktree development, and pull request handoff. Install the package with its `plugins/ai-delivery` directory available to the host plugin loader. Point the host at `plugins/ai-delivery/dist/mcp-launcher.js` from the verified package installation, set the consuming repository's selected author and reviewer credential environment outside source control, and use the public `runtime:stage` / `runtime:admit` setup operations described in the [package guide](../../README.md) before a lifecycle write. Stage returns the actual bundled launcher path without switching host references; admission is a separate explicit final write that rechecks the reviewed archive, consumer source/configuration, configured actors and installed bytes. The existing consumer installer owns host activation and rollback. Restart the host after installation so it loads the new launcher. A read-only `issue_info` call can confirm repository selection; `issue_pr_create` with `dryRun: true` reports effective actors and rule visibility before publication. Keep one active writer per issue and preserve its original worktree owner when upgrading.
