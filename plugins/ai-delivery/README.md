# ai-delivery plugin

Thin host plugin for `@aviaratech/ai-delivery`. The launcher starts the installed package's `mcp:serve` command over stdio. MCP schemas, GitHub operations, worktree handling, and delivery logic remain in the package.

The bundled skills cover issue intake, prepared worktree development, and pull request handoff. Install the package with its `plugins/ai-delivery` directory available to the host plugin loader. Point the host at `plugins/ai-delivery/dist/mcp-launcher.js` from the verified package installation, set the consuming repository's selected author and reviewer credential environment outside source control, and issue the private runtime-admission record described in the [package guide](../../README.md) before a lifecycle write. Restart the host after installation so it loads the new launcher. A read-only `issue_info` call can confirm repository selection; `issue_pr_create` with `dryRun: true` reports effective actors and rule visibility before publication. Keep one active writer per issue and preserve its original worktree owner when upgrading.
